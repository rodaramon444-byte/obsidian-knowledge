### 1. Definicions

1. **Symfony:** Framework de PHP per crear aplicacions web.
2. **NetBeans:** Entorn de desenvolupament per programar en diferents llenguatges.
3. **Host virtual:** Permet tenir diferents webs o dominis en un mateix servidor.
4. **Framework:** Conjunt d’eines i estructures que faciliten el desenvolupament d’aplicacions.
5. **Doctrine:** Eina que facilita treballar amb bases de dades des de PHP.
6. **Composer:** Gestor de dependències i paquets per a PHP.
7. **Laravel:** Framework de PHP per desenvolupar aplicacions web.
8. **Eclipse:** Entorn de desenvolupament utilitzat per programar en diversos llenguatges.
9. **Vagrant:** Eina per crear i gestionar entorns virtuals de desenvolupament.
10. **WAMP:** Entorn per executar webs amb Windows, Apache, MySQL i PHP.
11. **Joomla:** Gestor de continguts per crear i administrar pàgines web.
12. **MVC:** Patró que separa una aplicació en model, vista i controlador.
13. **Node.js:** Entorn que permet executar JavaScript fora del navegador.
14. **JavaScript:** Llenguatge de programació molt utilitzat per donar interactivitat a les webs.
15. **Responsive:** Disseny web que s’adapta a diferents mides de pantalla.
16. **Oracle:** Sistema de gestió de bases de dades.
17. **LAMP:** Entorn format per Linux, Apache, MySQL i PHP.
18. **PhpStorm:** Entorn de desenvolupament especialitzat en PHP.
19. **Django:** Framework de Python per desenvolupar aplicacions web.
20. **PHP:** Llenguatge de programació molt utilitzat al servidor.
21. **MariaDB:** Sistema de gestió de bases de dades relacionals.
22. **GitHub:** Plataforma per guardar i gestionar projectes de codi amb Git.
23. **WordPress:** Gestor de continguts molt utilitzat per crear pàgines web.
24. **Angular:** Framework per desenvolupar aplicacions web amb JavaScript/TypeScript.
25. **JSON:** Format de text utilitzat per guardar i intercanviar dades.
26. **SQL Server:** Sistema de gestió de bases de dades de Microsoft.
27. **PostgreSQL:** Sistema de gestió de bases de dades relacionals.
28. **AJAX:** Tècnica que permet actualitzar dades d’una web sense recarregar tota la pàgina.
29. **Phaser:** Framework de JavaScript per crear videojocs.
30. **MongoDB:** Sistema de bases de dades NoSQL orientat a documents.
31. **Bootstrap:** Framework per facilitar el disseny de pàgines web responsive.
32. **jQuery:** Llibreria de JavaScript que facilita la manipulació de pàgines web.
33. **HTML:** Llenguatge de marques utilitzat per estructurar el contingut d’una web.
34. **XHTML:** Versió d’HTML que segueix unes normes més estrictes basades en XML.
35. **Drupal:** Gestor de continguts per crear i administrar llocs web.
36. **Ionic:** Framework per desenvolupar aplicacions mòbils i web.
37. **Rails:** Framework de Ruby per desenvolupar aplicacions web.
38. **MySQL:** Sistema de gestió de bases de dades relacionals.
39. **Java:** Llenguatge de programació orientat a objectes i multiplataforma.
40. **Ruby:** Llenguatge de programació orientat a objectes.
41. **XAMPP:** Entorn que permet muntar fàcilment un servidor web local.
42. **Twig:** Motor de plantilles utilitzat principalment amb PHP.
43. **CSS:** Llenguatge utilitzat per donar estil i disseny a les pàgines web.
44. **Bundle:** Paquet que agrupa funcionalitats o recursos d’una aplicació.
