**1. Identificació dels actius**

En primer lloc, s’identifiquen els diferents actius que formen part del sistema informàtic de l’IES de l’Ebre. Aquests actius seran la base sobre la qual es realitzarà posteriorment l’anàlisi de riscos, identificant les amenaces que els poden afectar i les mesures que es poden aplicar per reduir aquests riscos.

A partir de la informació que ens dona la pràctica, tenim aquests actius:

| ID  | Actiu                   | Descripció                                                                                                        |
| --- | ----------------------- | ----------------------------------------------------------------------------------------------------------------- |
| A01 | Ordinadors generals     | Equips de les aules, biblioteca, sala de professors, etc. Estan congelats i no emmagatzemen informació rellevant. |
| A02 | Ordinadors de Direcció  | Equips que poden contenir fitxers i dades crítiques del centre.                                                   |
| A03 | Disc dur en xarxa       | Emmagatzema diàriament les dades importants de Direcció.                                                          |
| A04 | Servidor web / Moodle   | Servidor que allotja Moodle i els materials dels cursos.                                                          |
| A05 | Google Drive corporatiu | Carpetes compartides utilitzades per intercanviar documentació entre el personal.                                 |
| A06 | Xarxa Wi-Fi             | Xarxa sense fils disponible per a professors i alumnes.                                                           |
| A07 | Dades d'Esfer@          | Expedients, matrícules, notes i altra informació acadèmica dels alumnes.                                          |
| A08 | Còpies de seguretat     | Còpies de les dades del centre i del contingut de Moodle.                                                         |
**2. Preparació de les eines per a l’anàlisi de riscos**

Per realitzar l’anàlisi de riscos s’utilitzaran els fulls de càlcul proposats pel model INCIBE. Un dels fulls permetrà registrar i valorar els riscos associats als actius del centre, mentre que l’altre s’utilitzarà per registrar, classificar i prioritzar les iniciatives destinades a reduir aquests riscos.
